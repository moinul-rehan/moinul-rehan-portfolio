Drop project photos here using this naming convention — the slideshow
picks them up automatically, no code changes needed:

  handynaija-1.jpg
  handynaija-2.jpg
  handynaija-3.jpg

  suede-1.jpg
  suede-2.jpg
  suede-3.jpg

  terrava-1.jpg
  terrava-2.jpg
  terrava-3.jpg

Recommended: roughly 3:2 or 16:10 landscape shots, at least 800px wide.
The preview panel crops to fill its box (object-fit: cover), so center
the important part of each photo.

Any image format works (.jpg, .png, .webp) — if you use a different
extension, update the matching src="images/..." paths in index.html.
